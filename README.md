# Nokia Phone Launcher (Android)
Launcher thật mô phỏng điện thoại cục gạch Nokia: thân máy + bàn phím cố định, chỉ màn hình LCD nhỏ thay đổi.

- Menu: Ứng dụng (liệt kê app đã cài, mở app), Danh bạ, Tin nhắn, Đồng hồ, Rắn săn mồi, Cài đặt
- Màn hình chờ: bấm số + "Gọi" để mở trình quay số thật
- Nút Home -> về màn hình chờ, nút Back -> lùi một cấp

Build APK: push lên GitHub -> Actions -> "Build APK" -> tải artifact `nokia-phone-apk`.
Đặt làm launcher: Cài đặt máy -> Ứng dụng mặc định -> Ứng dụng màn hình chính -> Nokia Phone
(hoặc trong app: Menu -> Cài đặt -> Chọn launcher).
